= Stateful Artefacts Roadmap

The authoritative, machine-readable roadmap lives in
`.machine_readable/descriptiles/STATE.a2ml` under `[route-to-mvp]`. This page is a
human-readable summary of it.

== Current Status

Early *alpha*. The last Component Readiness Grade assessment was *X* on
2026-07-02 and is historical; refresh it before using the grade for release
claims. A v0 state-record schema and Zig core now exist in `src/definitions/`
and `src/core/`, alongside the typed
ABI/FFI seam and a tested PROVISIONAL local JSON serializer. The broader
Reposystem graph/scenario domain content has not been transferred. Lifecycle
proof sources exist but are not machine-checked in the current CI; the
Rust-versus-Zig core decision and the MPL-2.0-versus-PMPL-1.0 licence question
remain unresolved. The VeriSimDB boundary is intentionally local-only: no
mapping from this record to the current upstream Octad API/model or network
sink is in this repository's scope (see
link:../decisions/0005-verisimdb-local-only-boundary.adoc[ADR-005]). See
link:READINESS.adoc[READINESS.adoc],
link:../../AFFIRMATION.adoc[AFFIRMATION.adoc], and
link:../REPOSITORY-ULTRAPLAN.adoc[the repository ultraplan].
