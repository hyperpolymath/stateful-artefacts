= Stateful Artefacts Roadmap

The authoritative, machine-readable roadmap lives in
`.machine_readable/6a2/STATE.a2ml` under `[route-to-mvp]`. This page is a
human-readable summary of it.

== Current Status

Early *alpha* (Component Readiness Grade *X*). The repository was instantiated
from the RSR template; the ABI/FFI seam builds and its Zig tests pass, but there
is *no domain implementation yet* — `src/core` is empty scaffolding pending a
content re-transfer from `hyperpolymath/reposystem`. The project definition is
*PROVISIONAL* and the licence question (MPL-2.0 here vs reposystem's PMPL-1.0)
is *unresolved*. See link:READINESS.adoc[READINESS.adoc] and
link:../../AFFIRMATION.adoc[AFFIRMATION.adoc].
