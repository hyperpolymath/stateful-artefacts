= LLM Warmup — stateful-artefacts (Developer)

== What is stateful-artefacts?

The state-carrying artefact layer of the Reposystem/OPSM stack: a canonical
machine-readable state record (identity, provenance, lifecycle, verification)
exposed over a formally-typed C ABI (Idris2-proven layout, Zig
implementation). See `README.adoc` for the full overview, and
`0-AI-MANIFEST.a2ml` for the universal AI-agent entry point.

== Key Commands

* `just doctor` — self-diagnostic (checks required tools)
* `just build` — build the FFI seam
* `just test` — run Zig unit + integration tests
* `just quality` — format-check + test
* `just aspect` — SPDX/dangerous-pattern/ABI-parity checks
