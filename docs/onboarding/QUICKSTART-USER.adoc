= Stateful Artefacts — Quick Start for Consumers
:toc:
:toclevels: 2

== What is stateful-artefacts?

*stateful-artefacts* is a library, not a runnable application. It provides
one canonical, machine-readable *state record* (identity, provenance,
lifecycle phase, verification status) that any artefact can carry, exposed
over a formally-typed C ABI (Idris2-proven layout, Zig implementation). See
link:../../README.adoc[README.adoc] for the full pitch.

If you are looking to develop or modify the library itself, see
link:QUICKSTART-DEV.adoc[QUICKSTART-DEV] instead. If you are packaging or
deploying it, see link:QUICKSTART-MAINTAINER.adoc[QUICKSTART-MAINTAINER].

== Prerequisites

* **Zig** 0.15.2+ if building from source (https://ziglang.org/download/[install guide])
* **just** — task runner (https://github.com/casey/just[install guide]) — optional, only needed if building from source
* A C, Idris2, or any FFI-capable language toolchain to link against the built library

== Get the Library

=== Option 1: Build from source

[source,bash]
----
git clone https://github.com/hyperpolymath/stateful-artefacts.git
cd stateful-artefacts
just build-release
----

Output: `src/interface/ffi/zig-out/lib/libstateful_artefacts.{a,so}` and the
C header at `src/interface/generated/abi/stateful_artefacts.h`.

=== Option 2: Packaging

See link:QUICKSTART-MAINTAINER.adoc[QUICKSTART-MAINTAINER] for Guix/Nix/
container packaging paths.

== Using the Library

Link against `libstateful_artefacts` and include
`src/interface/generated/abi/stateful_artefacts.h`. Every exported symbol is
prefixed `stateful_artefacts_`; the ABI is documented in
link:../developer/ABI-FFI-README.adoc[ABI-FFI-README.adoc] and the record
schema in link:../spec/ARTEFACT-STATE-RECORD.adoc[ARTEFACT-STATE-RECORD.adoc].
`src/interface/ffi/test/integration_test.zig` is a working, runnable example
of calling the library entirely through the C ABI (handle lifecycle, the
artefact-state-record, error handling).

[source,c]
----
#include "stateful_artefacts.h"

StatefulArtefactsHandle *h = stateful_artefacts_init();
if (h) {
    /* ... use the handle ... */
    stateful_artefacts_free(h);
}
----

== Self-Diagnostic

If something isn't working with a from-source build:

[source,bash]
----
just doctor
----

This checks required tools (`just`, `git`, `zig`) are present.
