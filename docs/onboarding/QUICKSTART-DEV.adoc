= Stateful Artefacts — Quick Start for Developers
:toc:
:toclevels: 2

== Tech Stack

* *Zig* (0.15.2+) — C-ABI FFI seam (`src/interface/ffi/`)
* *Idris2* — formally-typed ABI layer and layout proofs (`src/interface/Abi/`, `abi.ipkg`)
* *Rust* — planned core implementation (lands with the reposystem content re-transfer)
* *just* — task runner; *AsciiDoc* — prose

== Set Up Development Environment

=== Option A: Guix (preferred)

[source,bash]
----
guix shell
----

=== Option B: Nix (fallback)

[source,bash]
----
nix develop
----

=== Option C: Manual

[source,bash]
----
git clone https://github.com/hyperpolymath/stateful-artefacts.git
cd stateful-artefacts
# Install the toolchain pinned in .tool-versions (Zig 0.15.2+, just; Idris2 optional)
just doctor                      # verify the required tools are present
----

== Build

[source,bash]
----
just build                       # or: cd src/interface/ffi && zig build
----

== Test

[source,bash]
----
just test                        # or: cd src/interface/ffi && zig build test
----

== Contractile Invariants

Read `.machine_readable/contractiles/` before making changes.
Key invariants that must never be violated:

* Every exported C symbol is prefixed `stateful_artefacts_` and declared on both the Zig and Idris2 sides.
* The Idris2 ABI layer stays `%default total`; no `believe_me` / `assert_total`.
* No TypeScript, npm, or bun anywhere in the repo (CI-enforced).
* Artefact state records remain backward-readable: schema changes are additive.

== LLM/AI Agent Development
