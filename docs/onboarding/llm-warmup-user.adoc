= LLM Warmup — stateful-artefacts (User)

== What is stateful-artefacts?

A library, not a runnable application: the state-carrying artefact layer of
the Reposystem/OPSM stack, exposed over a formally-typed C ABI. See
`README.adoc` for the full overview.

== Key Commands

* `just build-release` — build the library for consumption
* `just doctor` — self-diagnostic (checks required tools)
* `just test` — run the test suite
