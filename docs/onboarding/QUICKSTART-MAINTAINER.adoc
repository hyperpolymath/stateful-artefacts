= Stateful Artefacts — Quick Start for Platform Maintainers
:toc:
:toclevels: 2

== Overview

This guide covers packaging, deploying, and maintaining stateful-artefacts for
distribution on your platform.

== Runtime Dependencies

* None at runtime today — the FFI seam builds to a self-contained static/shared
  library (`libstateful_artefacts`) linked against libc only.
* Build-time: Zig 0.15.2+; Idris2 (optional, ABI typecheck only); just.

== Build from Source

[source,bash]
----
git clone https://github.com/hyperpolymath/stateful-artefacts.git
cd stateful-artefacts
just build-release
----

Output: `src/interface/ffi/zig-out/lib/libstateful_artefacts.{a,so}`

== Packaging

=== Guix

[source,bash]
----
guix build -f build/guix.scm
----

=== Nix

[source,bash]
----
nix build
----

=== Container (stapeln ecosystem)

[source,bash]
----
just container-build    # Build the image (build/Containerfile via cerro-torre / podman)
just container-sign     # Build, pack, sign and verify the bundle
----

=== Manual Package

NOTE: `just install` is currently a TODO stub. stateful-artefacts is a library
with no runnable binary today, so until the install recipe is wired up, package
by copying the built artefacts into your prefix:

[source,bash]
----
just build-release
install -Dm644 src/interface/ffi/zig-out/lib/libstateful_artefacts.a \
        "$PREFIX/lib/libstateful_artefacts.a"
install -Dm644 src/interface/ffi/zig-out/lib/libstateful_artefacts.so \
        "$PREFIX/lib/libstateful_artefacts.so"
install -Dm644 src/interface/generated/abi/stateful_artefacts.h \
        "$PREFIX/include/stateful_artefacts.h"
----

Files installed:

[cols="1,2"]
|===
| Path | Contents

| `$PREFIX/lib/`
| Static/shared library (`libstateful_artefacts.{a,so}`)

| `$PREFIX/include/`
| C ABI header (`stateful_artefacts.h`)

| `$PREFIX/share/doc/stateful-artefacts/`
| Documentation
|===

== Configuration

Default config location: `$XDG_CONFIG_HOME/stateful-artefacts/config.toml`

Fallback: `$HOME/.config/stateful-artefacts/config.toml`

== Health Checks

[source,bash]
----
just doctor            # Full diagnostic (checks tools, paths)
----

== Updating

[source,bash]
----
git pull
just build-release
----

Then re-run the manual package step above to refresh the installed artefacts.

Or via OPSM: `opsm update stateful-artefacts`
