= Stateful Artefacts — Quick Start for Platform Maintainers
:toc:
:toclevels: 2

== Overview

This guide covers packaging, deploying, and maintaining stateful-artefacts for
distribution on your platform.

== Runtime Dependencies

* None at runtime today — the FFI seam builds to a self-contained static/shared
  library (`libstateful_artefacts`) linked against libc only.
* Build-time: Zig 0.15.2+; Idris2 (optional, ABI typecheck only); just.

== Build from Source

[source,bash]
----
git clone https://github.com/hyperpolymath/stateful-artefacts.git
cd stateful-artefacts
just build-release
----

Output: `src/interface/ffi/zig-out/lib/libstateful_artefacts.{a,so}`

== Packaging

=== Guix

[source,bash]
----
guix build -f guix.scm
----

=== Nix

[source,bash]
----
nix build
----

=== Container (Stapeln)

[source,bash]
----
just stapeln-export    # Generates Containerfile
podman build -t stateful-artefacts .
----

=== Manual Package

[source,bash]
----
just install --prefix=/usr/local
----

Files installed:

[cols="1,2"]
|===
| Path | Contents

| `$PREFIX/bin/`
| Executables

| `$PREFIX/share/stateful-artefacts/`
| Data files, assets

| `$PREFIX/share/doc/stateful-artefacts/`
| Documentation

| `$PREFIX/share/applications/`
| .desktop file (Linux, if GUI)

| `$PREFIX/share/man/man1/`
| Man pages
|===

== Configuration

Default config location: `$XDG_CONFIG_HOME/stateful-artefacts/config.toml`

Fallback: `$HOME/.config/stateful-artefacts/config.toml`

== Health Checks

[source,bash]
----
just doctor            # Full diagnostic
just run --version   # Version check
just run --selftest  # Built-in self-test
----

== Updating

[source,bash]
----
git pull
just build-release
just install --prefix=/usr/local
----

Or via OPSM: `opsm update stateful-artefacts`

== Multi-Instance Deployment

For deploying multiple instances (e.g., different users or tenants):

[source,bash]
----
just install --prefix=/opt/stateful-artefacts-instance1 --config=/etc/stateful-artefacts/instance1.toml
just install --prefix=/opt/stateful-artefacts-instance2 --config=/etc/stateful-artefacts/instance2.toml
----

Each instance has isolated config, data, and logs.
