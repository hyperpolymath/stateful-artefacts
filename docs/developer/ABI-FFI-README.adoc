= ABI/FFI Standards

# STATEFUL_ARTEFACTS ABI/FFI Documentation

## Overview

This library follows the **Hyperpolymath RSR Standard** for ABI and FFI design:

- **ABI (Application Binary Interface)** defined in **Idris2** with formal proofs
- **FFI (Foreign Function Interface)** implemented in **Zig** for C compatibility
- **A hand-maintained C header** bridges the Idris2 ABI to the Zig FFI
- **Any language** can call through standard C ABI

## Result Canon (ADR-003)

Every FFI operation that can fail returns a single, shared result enum. The
five values, their C codes, and their names are **identical** across the Zig
implementation (`Result = enum(c_int)`), the Idris2 ABI (`data Result`), and
the C header:

| Code | Zig | Idris2 |
|------|-----|--------|
| 0 | `ok` | `Ok` |
| 1 | `error` | `Error` |
| 2 | `invalid_param` | `InvalidParam` |
| 3 | `out_of_memory` | `OutOfMemory` |
| 4 | `null_pointer` | `NullPointer` |

`Abi.Types.resultCode` / `resultFromCode` convert between the enum and the raw
`Bits32` returned across the boundary. Adding, removing, or renumbering a value
is a breaking ABI change: update all three sides and bump the ABI version.

library through the standard C ABI, and the Zig build has no external
dependencies.

## Why Idris2 for ABI?

### 1. **Formal Verification**

Idris2's dependent types allow proving properties about the ABI at compile-time:

```idris
-- Prove struct size is correct
public export
exampleStructSize : HasSize ExampleStruct 16

-- Prove field alignment is correct
public export
fieldAligned : Divides 8 (offsetOf ExampleStruct.field)

-- Prove ABI is platform-compatible
public export
abiCompatible : Compatible (ABI 1) (ABI 2)
```

### 2. **Type Safety**

Encode invariants that C/Zig cannot express:

```idris
-- Non-null pointer guaranteed at type level
data Handle : Type where
  MkHandle : (ptr : Bits64) -> {auto 0 nonNull : So (ptr /= 0)} -> Handle

-- Array with length proof
data Buffer : (n : Nat) -> Type where
  MkBuffer : Vect n Byte -> Buffer n
```

### 3. **Platform Abstraction**

Platform-specific types with compile-time selection:

```idris
CInt : Platform -> Type
CInt Linux = Bits32
CInt Windows = Bits32

CSize : Platform -> Type
CSize Linux = Bits64
CSize Windows = Bits64
```

### 4. **Safe Evolution**

Prove that new ABI versions are backward-compatible:

```idris
-- Compiler enforces compatibility
abiUpgrade : ABI 1 -> ABI 2
abiUpgrade old = MkABI2 {
  -- Must preserve all v1 fields
  v1_compat = old,
  -- Can add new fields
  new_features = defaults
}
```

## Why Zig for FFI?

### 1. **C ABI Compatibility**

Zig exports C-compatible functions naturally:

```zig
export fn library_function(param: i32) i32 {
    return param * 2;
}
```

### 2. **Memory Safety**

Compile-time safety without runtime overhead:

```zig
// Null check enforced at compile time
const handle = init() orelse return error.InitFailed;
defer free(handle);
```

### 3. **Cross-Compilation**

Built-in cross-compilation to any platform:

```bash
zig build -Dtarget=x86_64-linux
zig build -Dtarget=aarch64-macos
zig build -Dtarget=x86_64-windows
```

### 4. **Zero Dependencies**

No runtime, no libc required (unless explicitly needed):

```zig
// Minimal binary size
pub const lib = @import("std");
// Only includes what you use
```

## Building

### Build FFI Library

```bash
cd src/interface/ffi
zig build                         # Build debug
zig build -Doptimize=ReleaseFast  # Build optimized
zig build test                    # Run tests
```

### C Header

The C-consumer contract is the hand-maintained header
`src/interface/generated/abi/stateful_artefacts.h`. It mirrors the
`export fn stateful_artefacts_*` symbols in `src/interface/ffi/src/main.zig`
and the `%foreign` bindings in `src/interface/Abi/Foreign.idr` (modern Zig and
Idris2 no longer emit a usable C header automatically). When you add or change
an export, update all three in lock-step; `tests/aspect_tests.sh` checks
Idris2↔Zig symbol parity.

Verify the header parses:

```bash
gcc -fsyntax-only src/interface/generated/abi/stateful_artefacts.h
```

### Cross-Compile

```bash
cd src/interface/ffi

# Linux x86_64
zig build -Dtarget=x86_64-linux

# macOS ARM64
zig build -Dtarget=aarch64-macos

# Windows x86_64
zig build -Dtarget=x86_64-windows
```

## Usage

### From C

```c
#include "stateful_artefacts.h"

int main() {
    void* handle = stateful_artefacts_init();
    if (!handle) return 1;

    int result = stateful_artefacts_process(handle, 42);
    if (result != 0) {
        const char* err = stateful_artefacts_last_error();
        fprintf(stderr, "Error: %s\n", err);
    }

    stateful_artefacts_free(handle);
    return 0;
}
```

Compile with:
```bash
gcc -o example example.c -lstateful_artefacts -L./zig-out/lib
```

### From Idris2

```idris
import Abi.Foreign

main : IO ()
main = do
  Just handle <- init
    | Nothing => putStrLn "Failed to initialize"

  Right result <- process handle 42
    | Left err => putStrLn $ "Error: " ++ errorDescription err

  free handle
  putStrLn "Success"
```

### From Rust

```rust
#[link(name = "stateful_artefacts")]
extern "C" {
    fn stateful_artefacts_init() -> *mut std::ffi::c_void;
    fn stateful_artefacts_free(handle: *mut std::ffi::c_void);
    fn stateful_artefacts_process(handle: *mut std::ffi::c_void, input: u32) -> i32;
}

fn main() {
    unsafe {
        let handle = stateful_artefacts_init();
        assert!(!handle.is_null());

        let result = stateful_artefacts_process(handle, 42);
        assert_eq!(result, 0);

        stateful_artefacts_free(handle);
    }
}
```

### From Julia

```julia
const libstateful_artefacts = "libstateful_artefacts"

function init()
    handle = ccall((:stateful_artefacts_init, libstateful_artefacts), Ptr{Cvoid}, ())
    handle == C_NULL && error("Failed to initialize")
    handle
end

function process(handle, input)
    result = ccall((:stateful_artefacts_process, libstateful_artefacts), Cint, (Ptr{Cvoid}, UInt32), handle, input)
    result
end

function cleanup(handle)
    ccall((:stateful_artefacts_free, libstateful_artefacts), Cvoid, (Ptr{Cvoid},), handle)
end

# Usage
handle = init()
try
    result = process(handle, 42)
    println("Result: $result")
finally
    cleanup(handle)
end
```

## Contributing

When modifying the ABI/FFI:

1. **Update ABI first** (`src/interface/Abi/*.idr`)
   - Modify type definitions
   - Update proofs
   - Ensure backward compatibility

2. **Update the hand-maintained C header**
   (`src/interface/generated/abi/stateful_artefacts.h`) to match — keep it in
   lock-step with the Idris2 `%foreign` bindings and the Zig exports.

3. **Update FFI implementation** (`src/interface/ffi/src/main.zig`)
   - Implement new functions
   - Match ABI types exactly

4. **Add tests**
   - Unit tests in Zig
   - Integration tests
   - ABI verification tests

5. **Update documentation**
   - Function signatures
   - Usage examples
   - Migration guide (if breaking changes)
