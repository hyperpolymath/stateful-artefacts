# Project wiki sources

This directory is the Markdown home for forge-hosted wiki material.
General project documentation remains AsciiDoc elsewhere under `docs/`.

Start with the [project overview](../../README.adoc),
[developer quickstart](../onboarding/QUICKSTART-DEV.adoc), and
[artefact state-record specification](../spec/ARTEFACT-STATE-RECORD.adoc).
These are canonical documents, not duplicated wiki copies.

No automated wiki publication is configured here. A maintainer must configure
and verify forge synchronization before claiming these sources are published.

The [wiki source deed](wiki-sources_chora.deed) records scope and format rules.
